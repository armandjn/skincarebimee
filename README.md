# Skincare Bimee — website

Multi-page static website for **Skincare Bimee** (esthetician, Plano TX). Redesign of skincarebimee.com (Wix export lives in `raw/`, git-ignored).

- **Stack:** plain HTML/CSS/JS (no framework), generated by a small Node script. 3D hero uses three.js from a CDN.
- **Hosting (current):** Cloudflare Pages + Pages Functions + D1 → https://skincarebimee.pages.dev
- **Agents / new contributors:** start with `docs/HANDOFF.md` (state, done work, open tasks, permissions, gotchas).

## Layout

| Path | What |
|---|---|
| `tools/data.js` | All content: site info, 10 services, 3 blog posts |
| `tools/build.js` | Generates every `*.html` in the project root (`node tools/build.js`) |
| `tools/dist.js` | Cloudflare build step: copies the public site into `dist/` |
| `tools/shot.sh` | Headless-Chrome screenshot helper (needs a server on :4173) |
| `assets/css/style.css`, `assets/js/main.js`, `assets/js/hero3d.js` | Design system, interactions, 3D hero |
| `assets/img/` | Web-sized images |
| `functions/api/` | Cloudflare Pages Functions: forms (`book`, `contact`, `subscribe`, `gift`) and `admin/*` |
| `schema.sql` | D1 schema |
| `admin.html` | Admin panel (hand-written, not generated) |
| `_redirects`, `_headers` | Cloudflare redirects (old Wix URLs) and headers |

## Edit workflow

1. Change content in `tools/data.js` or page markup in `tools/build.js`.
2. `node tools/build.js` → regenerates HTML.
3. Preview: open `index.html`, or `npx http-server . -p 4173`. Debug flags: `?no3d` (skip WebGL), `?shot` (reveal everything, for screenshots).
4. Commit and push `main` → Cloudflare Pages builds automatically.

Do **not** hand-edit generated `*.html` (except `admin.html`) — they are overwritten by the build.
