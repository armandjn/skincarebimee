## 7. Gotchas

- The Bash tool collapses `\\` and mangles heredocs containing backslashes; write such files with Write/Edit. `rm -rf $VAR/*` is blocked — use literal paths. `sleep` chains are blocked; use Monitor / run_in_background.
- Headless Chrome (`tools/shot.sh`) hangs on the WebGL hero → use `?shot&no3d`; it has a ~500 px minimum width, so check mobile overflow with JS in the in-app browser (`resize_window` preset `mobile`, then reset to `desktop`).
- Intersection-observer reveals have a 2.5 s failsafe; `clip-path` reveals were removed because they never intersected.
- Line endings: Git warns LF→CRLF on Windows; harmless.
- Cloudflare edge/Pages cache can serve stale files for ~20+ min after a deploy; test with a random query string to see the real new content.
